# Academic Personal Website

A professional academic personal website — HTML/CSS/JavaScript — ready for GitHub Pages.

## Structure

```text
.
├── index.html
├── data/
│   └── profile.js
├── assets/
│   ├── css/style.css
│   ├── js/main.js
│   ├── img/profile.jpg
│   └── img/favicon.svg
└── README.md
```

## Customization

### 1. Personal information

Edit `data/profile.js`.

### 2. Website content

Edit `index.html` to update:
- your full name;
- laboratory and affiliation;
- exact thesis title;
- academic background;
- publications;
- projects;
- contact details.

### 3. Profile photo

The current profile photo is:

`assets/img/profile.jpg`

Replace it with another image while keeping the same filename.

### 4. CV

Add your PDF here:

`assets/cv.pdf`

### 5. Academic links

Replace the `#` placeholders with your real:
- ORCID
- Google Scholar
- GitHub
- LinkedIn

## Deploy on GitHub Pages

Create a GitHub repository and upload the contents of this folder to the repository root.

Then go to:

`Settings` → `Pages` → `Deploy from a branch` → `main` → `/ (root)` → `Save`.

## Custom domain

You can later connect a personal domain from:

`Settings` → `Pages` → `Custom domain`.

## Language

The website interface and visible content are designed to be fully in English for an international academic audience.
